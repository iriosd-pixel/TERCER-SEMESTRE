Hola mundo: selector por ID

¿Qué hay?: otro selector por ID

1. Elemento con ambas clases (.nodo.cabeza)

Ana tiene nodo y cabeza en el mismo elemento: borde y fondo celeste.

2. Elemento con solo una clase (.nodo)

Luis solo tiene nodo: tiene borde, pero no el fondo celeste de .nodo.cabeza.

3. Una clase dentro de otra (.nodo .cabeza)

Luis tiene nodo; este texto tiene cabeza y está dentro de nodo, por eso es rojo.

4. Selector con coma (.nodo, .cabeza)

Marta solo tiene cabeza; también usa la fuente Arial por la regla con coma.

5. Clase adicional (.color)

Este elemento tiene nodo y color: texto verde y borde morado.

6. Selectores por atributo

El borde morado identifica el campo de texto; el naranja, el numérico.

Este párrafo tiene data-estado="ocupado" y fondo celeste.

7. Estados interactivos

Pasa el mouse sobre el botón, mantenlo presionado y luego selecciona el campo.
